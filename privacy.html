Privacy Policy

My English Coach Backup · Effective October 24, 2026

This policy describes the intended handling of Google user data by a personal, single-user utility used by its operator. The utility may be in configuration or testing and is not offered as a public service.

Google data accessed and permissions

The utility uses the Google Drive API through the rclone command-line application, with permission authorized by the Google account owner. The https://www.googleapis.com/auth/drive OAuth scope technically permits viewing, creating, editing and deleting files across the authorized Google Drive account. The configured workflow is intended only to upload PostgreSQL backup archives to a designated private folder and verify their integrity using file metadata and checksums. It is not intended to browse or process other Drive files.

How data is used

When enabled, an automated workflow creates a backup of the operator's My English Coach PostgreSQL data and copies it to their own Google Drive folder. The workflow may read Google Drive file metadata needed to confirm that an archive was uploaded correctly. Google data is not used for advertising, personalized marketing, profiling, or training AI models.

Storage and processing

  • Database backup archives are stored in the operator's own private Google Drive account. Backup files may contain personal learning records and are not publicly shared.
  • During a backup job, an archive is temporarily handled on a GitHub-hosted Actions runner. The workflow is designed to remove temporary files at the end of the job and does not intentionally publish backup files as build artifacts or commit them to the repository.
  • Google OAuth authorization credentials, including refresh tokens, are intended to be stored in GitHub Actions encrypted repository secrets, not in the public source code or this public website.
  • Backup archives are not separately application-encrypted by the current planned workflow. Protection relies on the access controls of the Google Drive account and the private automation environment.

Sharing and disclosure

The operator does not sell Google user data, provide it to advertisers, or share it with other users. Google Drive and GitHub infrastructure are used solely for storage and execution of the intended backup operations, under their respective service terms. Information may be disclosed only if legally required.

Retention and deletion

Backups remain in the owner's Google Drive until manually deleted or removed under any retention rules the owner may set in the future. The workflow does not currently delete old backup files automatically. The owner can remove the stored archives directly in Google Drive and can revoke the app's Google account access at any time through Google Account security settings. Revoking access prevents further authorized Drive operations but does not itself delete existing backup files.

Access and control

This is a single-user utility. The authorized account owner controls its Google OAuth grant, GitHub Actions configuration and destination Drive files. If the account or backup process is no longer needed, the owner can disable the workflow and revoke the Google access grant.

Contact

Questions about this project or its privacy practices may be raised through its GitHub repository issues. GitHub issues are public: do not post passwords, tokens, backup contents, or private learning records.

Changes

This policy may be updated if the utility's operation or data practices change. The revised effective date and policy will be published on this page.
