My English Coach Backup

My English Coach Backup is a private, single-user utility intended to help its owner preserve learning records from a PostgreSQL database by storing backup archives in their own Google Drive account.

What it does

When configured and enabled, a scheduled GitHub Actions workflow connects to the owner's private Railway PostgreSQL instance, generates a database backup, and uploads the file to a designated private Google Drive folder using rclone. It verifies the upload's checksum and does not intentionally modify the source database.

Why Google Drive access is requested

Google Drive access is used to upload and verify the owner's backup archives. The OAuth permission technically grants broad access to files in the authorized Google Drive account, but the workflow is designed to operate in the designated backup folder only. It is not a public file-sharing, advertising, or analytics service.

Availability

This is a personal utility, not a public signup service. Backup automation may remain disabled until its owner completes configuration and testing.
